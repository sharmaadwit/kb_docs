# When to Use RCS — Readiness Diagnosis Guide

## Diagnosis: Is RCS Right for Your Business?

Evaluate three readiness factors:
1. **Message volume** (scale determines ROI)
2. **Carrier readiness by region** (geographic availability varies)
3. **Message type fit** (rich media benefits)

## Context: RCS vs SMS Tradeoffs

| Factor | SMS | RCS |
|--------|-----|-----|
| Carrier Coverage | 99%+ globally | 60-90% (regional variation) |
| Delivery Speed | 5-15 seconds | 2-8 seconds |
| Cost per Message | $0.005-0.01 | $0.02-0.04 |
| Open Rates | 20-30% (SMS engagement) | 40-60% (with rich content) |
| Rich Content | No (text only) | Yes (images, buttons, cards) |
| Setup Time | 1-2 days | 4-6 weeks (carrier approval) |

## Options: Three Adoption Paths

### Path 1: SMS-First, RCS Later (Low Risk)
Launch with SMS, add RCS after 3-6 months if ROI proven.

### Path 2: RCS-First, SMS Fallback (Optimistic)
Start with RCS immediately, SMS for automatic fallback.

### Path 3: Hybrid from Day 1 (Balanced)
SMS launches immediately, RCS in parallel (4-6 weeks).

## Recommended Approach

**For most teams: Path 1 (SMS-First) → Path 3 (Hybrid) at 6 months.**

Validates product-market fit with SMS, measures baseline engagement, plans RCS expansion only if SMS ROI justified.
